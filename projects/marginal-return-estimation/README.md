# Project 20: next-dollar return estimation

**Source test:** [OpenAI Machine Learning Engineer, Growth](https://openai.com/careers/machine-learning-engineer-growth-san-francisco/) asks for marketing response, diminishing returns, uncertainty, and a choice of where the next dollar should go. Its [employer ATS posting](https://jobs.ashbyhq.com/openai/70042d81-4db6-4c5c-bdb2-76c133ee2917) was last published October 13, 2026 in the October 14 audit; that timestamp can reflect republication. Can randomized spend levels support a conservative next-step allocation decision?

Run `python3 estimate.py` and `python3 -m unittest test_estimate.py` here. The script creates **synthetic** blocked experiments for three channels at spend levels $0, $100, $200, and $300. Each block has four comparable subunits randomly assigned to levels. The estimator sees only assignments and outcomes, computes each adjacent $100 return with a paired block bootstrap interval, and chooses the channel with the highest **positive lower bound** for the next step. It abstains if all lower bounds are nonpositive.

The simulation's log response curves are deliberately saturating and visible in the source. They are never read by the estimator. Outcomes are arbitrary units, not revenue or conversions. Tests check complete arm assignment, order invariance, diminishing returns with zero noise, and abstention when every next step is negative. The bootstrap intervals are descriptive and do not adjust for choosing the largest result across channels. The output is an illustration of design and inference, **not an observed marketing effect**. Real ad spend introduces auction interference, conversion delay, heterogeneous markets, attribution errors, and budget constraints not represented here. A real decision would need a prospective geo or user experiment and finance-approved value metric.
